# practice/

**Yatra Demo Rail** — a completely fictional train booking website, used for
demos and tests.

It is fictional on purpose: no real brand names, no real logos, and nothing
here ever talks to a real booking system. That means we can demo a "payment"
page and an "OTP" box safely, to show that Daari pauses before money and never
sends what the user typed to the AI.

Built in Phase 1 as plain static HTML and JavaScript.
