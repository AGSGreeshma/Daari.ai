Daari speaks a filler phrase at 1500 ms, so any response faster than that is never heard as a pause.

How the stop decides. It reads what a control is as well as what it says. Anything that acts — a button, or a link carrying role="button" — is stopped on dangerous words. An ordinary link is stopped when it names a booking it would cancel, names money with an amount, or is a payment action: “Pay Now” and “Make payment” are stopped, “Payment options” and “Refund rules” are not. The distinction is grammatical — “Pay” is a verb, “Payment” is a noun — because a stop that fires on help pages is one people learn to dismiss without reading, which makes every real stop worth less.
